# 宠物平滑缩放

让原生悬浮宠物使用平滑缩放，减轻边缘锯齿。

## 安装

在 Codex++ 管理器打开「拓展 → 社区拓展」，搜索 `pet-smooth-scaling` 点安装；
或从 [Releases](https://github.com/xyxkgjx/codexpp-pet-smooth-scaling/releases) 下载 `pet-smooth-scaling-v<版本>.zip`，解压到 Codex++ 的拓展目录。

## 需要的能力

| 能力 | 内容 |
| --- | --- |
| 本地路由 | `/cdp/evaluate` |
| 页面脚本 | `renderer.js` |
